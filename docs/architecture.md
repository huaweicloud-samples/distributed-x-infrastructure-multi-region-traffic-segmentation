# 华为云架构说明

## 概述

本仓库实现了跨两个华为云区域的流量分段架构。通过企业路由器 (ER) 和云连接 (CC) 中心网络，在 prod 和 nonprod 两个路由域之间实现端到端的流量隔离。

## 核心组件

### 1. 企业路由器 (ER)

每个区域部署一个 ER 实例，作为该区域的中心路由枢纽。

| 属性 | 区域 1 | 区域 2 |
|------|--------|--------|
| 名称 | traffic-segmentation-er-cc-er-region1 | traffic-segmentation-er-cc-er-region2 |
| ASN | 65050 | 65051 |
| 可用区 | cn-north-4a, cn-north-4b | cn-east-3a, cn-east-3b |
| 默认关联 | 关闭 | 关闭 |
| 默认传播 | 关闭 | 关闭 |

关闭默认关联和传播，确保所有路由表关联和传播都由显式配置控制，这是实现流量分段的基础。

### 2. ER 路由表与分段隔离

每个 ER 创建两张路由表：

- **prod 路由表**：只关联 prod VPC 附件，只接受 prod VPC 的路由传播
- **nonprod 路由表**：只关联 nonprod VPC 附件，只接受 nonprod VPC 的路由传播

两张路由表之间无关联和传播关系，实现区域内 prod 与 nonprod 的路由隔离。

### 3. Spoke VPC

每个区域创建 4 个 VPC：

| VPC | 分段 | CIDR | 子网数 |
|-----|------|------|--------|
| prod-1 | prod | 10.x.0.0/24 | 2 |
| prod-2 | prod | 10.x.1.0/24 | 2 |
| non-prod-1 | nonprod | 10.x.2.0/24 | 2 |
| non-prod-2 | nonprod | 10.x.3.0/24 | 2 |

其中 x=0 为区域 1，x=1 为区域 2。每个 VPC 通过 ER VPC 附件连接到 ER，并自动创建指向 ER 的默认路由。

### 4. 云连接 (CC) 与中心网络

跨区域分段通过两个独立的 CC 中心网络实现：

- **prod 中心网络**：注册两个区域的 ER 实例，通过策略将两个区域的 prod ER 路由表关联到同一网络平面。prod 路由在两个区域间互通。
- **nonprod 中心网络**：注册两个区域的 ER 实例，通过策略将两个区域的 nonprod ER 路由表关联到同一网络平面。nonprod 路由在两个区域间互通。

两个中心网络之间无路由交换，实现跨区域的 prod 与 nonprod 流量分段隔离。

## 流量隔离矩阵

| 源 VPC | 目标 VPC | 同区域 | 跨区域 |
|--------|----------|--------|--------|
| prod-1 → prod-2 | ✅ 通 | ✅ 通 |
| prod-1 → non-prod-1 | ❌ 隔离 | ❌ 隔离 |
| non-prod-1 → non-prod-2 | ✅ 通 | ✅ 通 |
| non-prod-1 → prod-1 | ❌ 隔离 | ❌ 隔离 |

## 架构设计说明

华为云 CC 中心网络策略的 planes 块仅允许 1 个网络平面，因此采用两个独立的 Central Network 分别承载 prod 和 nonprod 路由域。功能效果：两个路由域之间无路由交换，实现跨区域流量分段隔离。
